# Image Assets Guide for Bradley's Window Cleaning

This folder holds all image assets used on the website. When photos are available, drop them into the appropriate folders listed below and update the asset paths in `src/config/site.ts`, `src/data/services.ts`, `src/data/areas.ts`, or `src/data/gallery.ts`.

All placeholder components will automatically transition to displaying the real images without any layout shift.

## Alt Text Guidelines
Always use descriptive, keyword-aware alt text incorporating the service and location:
- Formula: `[Service or subject] in [Town] by Bradley's Window Cleaning`
- Example: `"Streak-free domestic window cleaning in Long Eaton by Bradley's Window Cleaning"`
- Decorative images: Use empty alt text `alt=""`.
